L’idée

Avant de vous rencontrer, vous avez déjà quelque chose à vous dire.

Nous réunissons quatre personnes qui pourraient avoir envie de se rencontrer. Elles reçoivent le même livre, le lisent pendant dix jours, puis se retrouvent autour d’un dîner.

Le livre n’est pas la destination. C’est le point de départ.
